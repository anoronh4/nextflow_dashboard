Effective CPU cores actively computing, stacked by sample. Each task contributes %cpu ÷ 100 — its real utilization regardless of how many cores were allocated. Compare with the Allocated tab to spot over-provisioned processes.

Total RAM requested/allocated per job, stacked by sample. Uses the memory directive from the pipeline config — the ceiling each job was granted, regardless of what it actually used.
